# Reachy Mini hardware profile provenance

The constants in this crate are transcribed from
`src/reachy_mini/assets/config/hardware_config.yaml` in
`pollen-robotics/reachy_mini` commit
`20bc9eedc81ddc552235d222ca7e39205b2c2481` (Apache-2.0).

The probe uses generic `rustypot` Dynamixel Protocol 2 reads only. It does not
depend on or reproduce the Reachy-specific motor-controller package.
