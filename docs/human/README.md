# Human Documentation

The intentionally small human-facing surface is:

- [`README.md`](../../README.md) for purpose and runnable entrypoints;
- [`ARCHITECTURE.md`](../../ARCHITECTURE.md) for the current code and contract map;
- [`STATUS.md`](../../STATUS.md) for current state, blocker, and next action;
- [`docs/architecture/`](../architecture/) for durable architecture detail;
- [`docs/glossary.md`](../glossary.md) for canonical vocabulary.

`docs/plans/**`, `docs/status/active/**`, `docs/deep-research/**`, and
`docs/decisions/**` are planning, active execution state, evidence, or decision
surfaces. They support the human docs but are not all required first reads.
